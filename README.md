# BatteryPC

An Android application to control and fake battery level using Shizuku service. Developed by SABIR7718.

## Features

- Fake battery level (0-100% via seekbar, 0-9999% via text input)
- Toggle charging state
- Battery widget for home screen
- Shizuku-based rootless shell execution
- Beautiful neon UI with dark theme

## Requirements

- Android 6.0+ (API 26)
- Shizuku app running
- Shizuku permission granted to BatteryPC

## How to Use

1. Install and start Shizuku app
2. Grant BatteryPC permission in Shizuku
3. Set desired battery level using seekbar or text input
4. Toggle charging state as needed

## Development

Android project using Java and Gradle.

### Requirements
- Android Studio
- Android SDK 30
- Java 17
